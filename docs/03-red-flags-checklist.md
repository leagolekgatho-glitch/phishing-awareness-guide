# Phishing Red Flags Checklist

## Sender
- [ ] Email address matches the real organisation's domain
- [ ] Sender is someone I expect to hear from

## Content
- [ ] No urgent or threatening language
- [ ] No spelling or grammar errors
- [ ] No request for passwords or PINs

## Links and Attachments
- [ ] Link address matches where it claims to go (hover to check)
- [ ] No unexpected attachments

## Final Check
- [ ] I verified through a trusted, separate channel

If any box fails: **do not click. Report it.**
