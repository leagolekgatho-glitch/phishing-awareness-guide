# phishing-awareness-guide
A beginner-friendly guide to detecting, avoiding and reporting phishing attacks
## Overview
Phishing is one of the most common ways attackers steal passwords, money and data. This mini-project is a set of short guides, a checklist and a reporting template that help people recognise phishing and respond correctly.

## Who It's For
Students, staff and everyday internet users with no technical background.

## What This Project Covers
- What phishing is and why attackers use it
- Common types: email phishing, spear phishing, smishing, vishing, whaling
- A checklist of red flags to look for
- What to do if you fall for a phishing attack
- A template for reporting phishing incidents
- An annotated example of a fake phishing email

## How to Use
1. Read `01` and `02` to understand the basics.
2. Use the checklist in `03` whenever you get a suspicious message.
3. If you've clicked something, follow the steps in `04`.
4. Report the incident using the template in `05`.
5. Check the example in `examples/` to practise spotting red flags.

## Key Takeaways
- Stop and think before clicking links or opening attachments.
- Urgent or threatening messages are a warning sign.
- Always verify the sender through a separate, trusted channel.
- Report suspicious messages quickly.
